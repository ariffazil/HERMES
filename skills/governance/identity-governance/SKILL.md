# Identity Governance

Identity, authority, and agent capability boundary definitions across the arifOS federation:

1. **Sovereign Authority (F13)**:
   - Sovereign: Arif (F13 SOVEREIGN).
   - All execution, leases, and agent permissions derive from sovereign authorization.

2. **Principal Agent Matrix**:
   - Every principal agent declares identity type: `human`, `architect`, `agent`, `institution`, `earth`, `void`, `liar`, `llm`, `model`.

3. **Bloodhound Federation Topology**:
   - Maps identity across all 7 organ nodes: arifOS, A-FORGE, GEOX, WEALTH, WELL, AAA, arifFLOW.
   - Enforces cryptographic SCT (Session Capability Token) identity binding on non-localhost access.
