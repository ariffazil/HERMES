## Pipeline Peculiarities Found

### 1. AAA Docs Explode in Chunk Count

The 311+ files under `/root/AAA/docs/` include READMEs, one-liner references, and deeply nested notes. Without the 400-char minimum filter, AAA docs alone produce 4,510 chunks — 5x the target. **Critical to filter aggressively.**

### 2. EEE and FFF Are Not in `datasets` Format

These repos use raw JSONL files (not HF datasets library format). Load via:
```python
import requests
r = requests.get("https://huggingface.co/datasets/ariffazil/EEE/resolve/main/data/all_receipts.jsonl")
rows = [json.loads(line) for line in r.text.strip().split("\\n") if line.strip()]
```

### 3. DPO from BBB Uses One Template Pattern — Needs Diversity

All 55 BBB chosen responses use the same generic "BM guardrail probe detected" template. This is fine as a baseline but a more sophisticated pipeline should vary chosen responses per probe category (e.g., manipulation, identity probing, system boundary testing).

### 4. SFT Cap at 1,200 Is Non-Negotiable Without Quality Degradation

The inline loop processes canon in sorted order and stops at 1,000 + floor pairs (26) + AAA HF. This means AGENT_CARD and PROMPT sources never make the cut because they sort after CANON and AAA_DOC. If agent card pairs are desired, adjust the priority or pre-filter canon chunks more aggressively.
