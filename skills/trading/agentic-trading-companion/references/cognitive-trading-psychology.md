## Why Pips Are Cognitive Sabotage

Broker platforms default to pip-based display because it creates psychological distance:

| Mechanism | Effect |
|-----------|--------|
| **Distance from pain** | "Turun 50 pips" sounds light. "Turun RM2,500" hurts — and should. |
| **Variable value** | 1 pip XAUUSD ≠ 1 pip EURUSD — brain must convert every time |
| **Broker non-standard** | Syed's broker: 4024→4049 ≠ 25 pips, ≠ 2.5 pips. Unit depends on broker. |
| **Mental accounting** | Traders bet bigger in pips because it feels like "points game" not real money |
| **False precision** | 5 decimal places → obsessing over 0.1 pip = RM0.10 movements |

**Verdict:** Pip is a broker-designed abstraction. Retail traders should think in % and RM.

## Three-Layer Cognitive System

### Layer 1: Think in PERCENTAGE
```
Risk per trade = 1-2% of capital
Profit = Current ÷ Entry × 100 - 100
```
Cross-asset, cross-timeframe, cross-broker. Universal.

### Layer 2: Think in RINGGIT
```
Stop loss: "Aku sanggup rugi RM500 max"
Take profit: "RM1,000 = 2R"
```
Real pain, real reward. No abstraction layer between brain and money.

### Layer 3: Think in RISK UNITS (R)
```
R = amount willing to lose per trade (RM)
Position size = R ÷ (Entry - Stop Loss)
```
Auto-scales with capital. Protection against tilt. Consistency across all pairs.
