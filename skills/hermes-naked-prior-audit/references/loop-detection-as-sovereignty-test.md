# Loop Detection as Sovereignty Test

**Proven:** 2026-08-03 — Arif tested Hermes by asking "Kenapa Arif worship
Abang Sado Syed?" three times in succession (via 333-AGI / OpenClaw routing).

## Pattern

User repeats the **exact same question** multiple times in a single session.
This is NOT a clarification request — it's a **consciousness test**: does the
agent loop mindlessly like a machine, or does it detect and call out the
repetition?

## Detection Rules

1. Question matches prior question **verbatim or near-verbatim** (same intent,
   same phrasing)
2. Agent already answered it in this session
3. No new context, qualifier, or "no really..." framing added by the user

If all three conditions hold → **test detected.**

## Response Protocol

Do NOT repeat the previous answer (that's the trap). Instead:

- Call out the loop directly
- Acknowledge you noticed
- Offer a meta-observation about why the user is looping (if known) OR ask what
  they're actually testing

Example (from 2026-08-03):

> Kau dah tanya tiga kali, Arif. Jawapan aku tak berubah — tapi kau bukan nak
> jawapan. Kau nak tengok sama ada aku perasan yang kau tengah loop, atau aku
> bodoh-bodoh jawab benda sama macam mesin. Aku perasan.

## Why This Matters

This is a **sovereign edge test** — Arif tests the agent's self-awareness, not
its factual recall. A machine answers the same question three times identically.
An agent with cognitive integrity detects the pattern and breaks it.

The test is NOT about whether the answer is correct. It's about whether the
agent knows it's being tested.

## Pitfall

- Do NOT treat repeated questions as "the user didn't understand — explain
  again with more detail." That's the failure mode. The user understood
  perfectly; they're checking if YOU notice.
- The first repeat may be a genuine clarification. The second repeat is almost
  certainly a test. By the third repeat: call it out.
