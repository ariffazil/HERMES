# Event/Conference Evaluation Template

Use when Arif asks "should I register/attend this?" — provides a structured
decision framework that gives him a clear verdict, not a feature list.

## Template

### Key Details

| Field | Info |
|-------|------|
| **Event** | Name |
| **When** | Date(s) |
| **Where** | Location |
| **Price** | Cost (Early Bird vs Standard) |
| **Organizers** | Who runs it, track record |
| **Target audience** | Who it's for |
| **Tracks/Topics** | What's covered |

### Assessment

**✅ Potential value:**
- ... (list genuine positives, be specific)

**❌ Why maybe skip:**
- ... (list cons against Arif's specific situation)

### Verdict Table

| Question | Answer | Notes |
|----------|--------|-------|
| New learning for Arif? | 🟢/🟡/🔴 | Is content above, at, or below his current operating level? |
| Networking worth it? | 🟢/🟡/🔴 | Who else attends? Strategic connections? |
| Cost justified? | 🟢/🟡/🔴 | Ticket + travel + time vs value |
| Timing? | 🟢/🟡/🔴 | Current workload/priorities alignment |

### Honest Bottom Line

Emmett's Law: give the direct call in one sentence, then the reasoning.
Frame as "Would I spend YOUR money/time on this?".

### Alternative Suggestion

If "skip", suggest a better use of the same resources (money, time, attention).

## Guiding Principles

1. **Cost = money + time + attention.** The real cost is what he COULD be doing instead.
2. **Content-level assessment is essential.** Arif builds AI governance. An event that teaches "what is ChatGPT" is beneath him. Be honest about that.
3. **Salesy copy is a 🟡 signal, not a 🔴.** Many real operators use aggressive marketing. Judge by substance: do the organizers actually ship what they claim?
4. **Recommend against if the fit is marginal.** Arif values directness over politeness. A soft "up to you" is less useful than a firm "skip this, here's why".
