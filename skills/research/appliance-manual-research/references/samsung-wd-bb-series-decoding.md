# Samsung WD BB Series — Known Model Decoding

## Sticker Code → Retail Model

| Sticker Code | Decoded Retail Model | Market | Capacity |
|---|---|---|---|
| `W013B8944DGBF0 01` | `WD13BB944DGBFQ` | Malaysia | 13kg wash / 8kg dry |
| `WD13BB944DGBSC` | `WD13BB944DGBSC` | China | 13kg wash / 8kg dry |

**Decoding rule:** `W` → `WD`, `013` → `13` (capacity), `B8944` → `BB944` (series), `F0` → `FQ` (Malaysia color code) or `SC` (China suffix).

## SmartThings Sticker Location

On Samsung washer dryers, the SmartThings sticker is typically:
- On the **front panel** below the control panel
- Near the bottom right or left of the door frame
- A white rectangular label divided into left (SmartThings logo, black bg) and right (QR code, white bg) sections

## Error Codes (from manual)

| Code | Meaning | Action |
|---|---|---|
| `5C` / `5UD` | Water not draining | Check drain hose, debris filter |
| `UE` | Unbalanced load | Redistribute laundry |
| `LE` | Door lock/unlock failure | Restart cycle |
| `DC` | Door open | Close door properly |
| `OC` | Water overflow | Restart after spin |
| `1C` / `1E` | Water level / fill issue | Check water supply |
