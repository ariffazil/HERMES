## The Core Distinction

Do not collapse three different truth regimes into one:

### Level 1: Structural Truth (Math)

> "Is G derivable from axioms A1-A7?"

- What kills it: one logical counterexample within the axiom set
- Example: harmonic mean satisfies A1-A4 → uniqueness fails → A6+A7 needed
- Proof IS the answer: if the derivation is valid, the theorem holds
- This is what theorem provers (Lean, Coq) certify

### Level 2: Model Truth (Science)

> "Do the axioms correctly represent governance?"

- What kills it: one argument that the axioms misrepresent reality
- Example: "Why MUST governance be multiplicative?" — this is a science question
- Proof cannot answer this. Only justification of axioms can.
- This is what Popperian falsification addresses

### Level 3: Empirical Truth (Reality)

> "Does G predict real system failure?"

- What kills it: one measurement contradicting prediction
- Example: G=0.92 system collapses in production → model refuted
- This is what geological core samples do to basin models

## The Common Failure Mode

Claiming "proven" at Level 3 because Level 1 checks out.
A mathematically sound model with wrong axioms is still useless in reality.
